# Lens bank

Read when dreaming or when editing the bank. `ouroboros.py prepare` samples lenses from this
file by ID and prefers ones not used in the last four runs, so keep the line format
`- **<ID> · <Name>.** <move>`. IDs: A = transfer within the investigator's work, B = same
biology in another context, C = constraint inversion, W = wildcard far analogy (one per brief).

A lens is a forced move, not a topic. Apply it to a specific fragment and say what the move
predicts that the current framing does not. If it produces nothing specific, say so and drop it.

## A · Transfer within the investigator's work

- **A1 · Neighbor method.** Take a method, assay, control, statistical design or analysis from another registered wiki and ask which open question here it would discriminate.
- **A2 · Dataset already in hand.** Find an existing dataset (the investigator's or a public one named in a wiki) that already contains the answer if re-read with a different question or stratification.
- **A3 · Shared bottleneck.** Find two projects stuck on structurally the same problem (power, calibration, specificity, access to a cell population) and design one fix that serves both.
- **A4 · Result as tool.** Treat a finished result in one project as a reagent, marker, prior or stratifier for another.

## B · Same biology, different context

- **B1 · Same molecule, different organ.** Look up the established function of a gene, receptor or pathway from the fragment in another organ or tissue, and ask whether that function explains the observation here.
- **B2 · Same program, different developmental window.** Ask what the program does in the embryo, during regeneration, or in ageing, and whether that role predicts the phenotype here.
- **B3 · Same cell type, different species or model.** Ask what human genetics, zebrafish, organoids or another species show that the current model hides, or the reverse.
- **B4 · Same constraint, different niche.** Ask how another vascular bed, epithelium or tissue niche solves the same physical or signalling constraint.
- **B5 · Disease as a natural experiment.** Use human variants, syndromes or drug side effects as existing perturbations of the mechanism in question.
- **B6 · Physiology first.** Make flow, pressure, shear, oxygen, nutrient transport or mechanical load the hidden variable, and ask what the data look like if it drives the effect.

## C · Constraint inversion

- **C1 · Invert causality.** Treat the presumed consequence as the cause, and list what would have to be true for that to hold.
- **C2 · Artifact as signal.** Treat a technical nuisance (batch, dropout, coverage, background, dissociation stress) as biological information, or treat a celebrated signal as an artifact.
- **C3 · Delete the favorite.** Assume the central hypothesized factor is irrelevant and ask what else explains the same data.
- **C4 · Change the scale.** Move the effect to another level (molecule, cell, tissue, organism) or another time scale (minutes, development, lifetime).
- **C5 · The null as an answer.** Take an inconsistent or negative result at face value and ask what it rules out and what it implies.
- **C6 · Relax the hard constraint.** Remove the constraint the project treats as fixed (sample size, model system, assay, timeline) and ask which question becomes easy, then whether a cheap version exists.

## W · Wildcard far analogies

- **W1 · Ecology.** Niches, succession, keystone species, competition and carrying capacity.
- **W2 · Control engineering.** Feedback, set points, gain, delays, robustness and fragility.
- **W3 · Economics.** Allocation under scarcity, incentives, cost structures and market failure.
- **W4 · Networks and epidemics.** Spread, percolation thresholds, hubs and cascades.
- **W5 · Materials and phase transitions.** Tension, buckling, percolation and abrupt state changes.
- **W6 · Immune logic.** Tolerance, memory, clonal selection and self versus non-self.
- **W7 · Evolution.** Selection pressure, exaptation, tradeoffs and constraint.
